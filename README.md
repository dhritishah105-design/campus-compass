# Campus Compass

A student guide to Mumbai for NMIMS, built by Dhriti Shah.
Live at **https://dhritishah105-design.github.io/campus.compass/**

## What is in this repo

| File | What it is |
|---|---|
| `index.html` | The entire website. One file: markup, styling and scripts together. |
| `og-image.png` | The preview card shown when the link is shared on WhatsApp, Instagram or anywhere else. |
| `README.md` | This file. |

There is no build step and nothing to install. GitHub Pages serves `index.html`
directly, and a new version is live about a minute after you upload it.

## Adding listings and reviews — you do not edit this file

Services and student reviews come from a Google Form, through a Google Sheet,
straight onto the site. The two links that connect it all are near the top of
the script inside `index.html`:

```js
var FORM_URL      = '';   // your Google Form link
var SHEET_CSV_URL = '';   // your sheet, published to the web as CSV
```

Fill those in once and you never touch this file to add content again.

**Nothing published until you approve it.** The response sheet has a column
headed `Approved`. An entry appears on the site only when that column says
`yes`. Blank means invisible. If the column is missing or misspelt, the site
shows nothing at all rather than showing everything.

The site also honours what people chose under "Can we publish this?":
"without my name" publishes as *NMIMS student*, and "just for your information"
never appears at all.

Full setup and the weekly routine: https://claude.ai/artifact/BsQSJfg82Z5nPw3rodrNR1

## Where the Services lists came from

Each Services category opens with a short list gathered from web search as a
starting point. Nobody has tried them — each row says so, and each links to a
live Google Maps search rather than a stored phone number, so a listing cannot
go stale or send someone to a wrong number. Student submissions appear
underneath, under a "Sent in by students" label.

## Sections that stay hand-written

Rent, Eat, Study resources, Transport and Mumbai basics live in `index.html`
as ordinary markup, because that content is already written and rarely changes.
The tool linked above generates rows for those if you need them.

## Publishing a change

1. Upload the changed file here on GitHub, or commit and push it.
2. Wait about a minute for Pages to rebuild.
3. Hard-refresh the live page (Ctrl+Shift+R, or Cmd+Shift+R on a Mac).

Every previous version is kept in this repo's history, so a bad change can
always be reverted.

## Notes

- No fares or prices appear on the Transport and Mumbai basics pages on
  purpose. They change, and a wrong number is worse than none.
- This is an independent student project and not an official NMIMS website.
